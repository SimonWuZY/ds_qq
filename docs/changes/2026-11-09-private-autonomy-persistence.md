# 私聊、自动群聊与持久运行变更设计

## 目标与故障结论

增加好友私聊、每日私聊定制消息和受控主动群聊，并让现有 Mac 部署具备开机自启和进程恢复能力。

当前 NapCat 容器持续运行但反复出现 `Login Error ErrCode: 3`，主要是 QQ 登录凭证失效；基础设施无法替代扫码恢复。优先使用小号专用、固定运行环境和自动登录，避免频繁换设备/IP。

## 功能模块

1. **私聊**：`QQ_FRIEND_IDS` 白名单，私聊无需 @；复用媒体、人格和长期记忆，好友可管理自己的记忆。
2. **私聊定时**：`chat_type: private`，向白名单好友发送固定或 AI 文案，沿用每日去重。
3. **自动群聊**：默认关闭；至少 8 条新消息、20 分钟冷却、每日最多 10 次，之后按 8% 概率参与。
4. **本机持久运行**：Colima brew services，ds_qq/看板 launchd RunAtLoad + KeepAlive，bot 使用 caffeinate -i 减少 idle sleep。

## 数据设计

为避免重写现有数据库，正整数 scope 表示群，负整数 `-QQ号` 表示该好友私聊。QQ 号为正数，所以不与群冲突。统一 helper 负责转换；现有群数据不变。

新增 `ambient_state` 保存最近主动群聊的位置和时间；API 用途增加 `ambient`。`scheduled_runs` 继续按任务 ID 和日期去重。

## 安全边界

- 私聊与定时私聊都要求显式白名单，禁止陌生用户触发 API。
- 自动群聊默认关闭，只有用户明确开启才工作；消息仍不可信且不得覆盖系统规则。
- launchd 实际 plist 只写用户目录，公开模板不包含真实路径、Token 或 QQ 号。
- 自动登录不能绕过 QQ 扫码或风控；登录过期需要明确提示用户。

## 验证与回滚

- 私聊白名单、私聊上下文隔离、私聊媒体与命令、每日私聊去重。
- 自动群聊各阈值、概率、失败不推进、默认关闭。
- launchd 模板生成、加载、健康检查与 NapCat 重连。
- 新表和配置均可回退，不影响现有消息、记忆和定时任务。
