# 定时推送与扩展多模态变更设计

## 目标

让机器人能按本地配置每天在白名单群正常发言或 @固定成员，并扩展当前图片能力到视频抽帧与 B 站公开信息理解。

## 模块与文件

1. `scheduler.py`、`scheduler.example.json`：每日任务、静态/AI 文案、群内 @、配置热读、断线跳过。
2. `db.py`：新增 `scheduled_runs`，以任务 ID 和上海日期防止重复发送。
3. `bot.py`、`onebot.py`：共享 NapCat 连接、主动群发和视频段解析。
4. `video.py`：限时下载视频并调用本机 FFmpeg 抽最多 3 帧。
5. `links.py`：解析 B 站 BV 链接和 b23.tv 短链的公开元数据。
6. `docs/SCHEDULER_MEDIA.md`：配置示例、能力边界、运维与隐私。

## 数据与安全

- 仅允许白名单群，任务不能发送私聊或非白名单群。
- 只有成功发送才记录 `scheduled_runs`；失败可在后续进程重试，不重复记成功。
- AI 推送用途记为 `scheduled`，静态文案不调用 API。
- 视频限制 URL 协议、大小、下载与处理时间；帧按图片附件复用现有存储。
- B 站仅注入公开标题、简介、UP 主、时长等，不宣称完整观看视频或读取字幕。

## 验证与回滚

- 模拟时钟、连接和 DeepSeek，验证静态/AI 推送、@成员、热读、断线、重启去重与白名单。
- 模拟视频下载和 FFmpeg，随后用真实短视频验证抽帧。
- 模拟 B 站短链和公开 API，验证失败时文字降级。
- 新表与功能均可独立回退，不影响原始消息、人格和已有记忆。

## 实施结果

- 定时任务支持静态文案、AI 文案、群内 @、热读、白名单、断线跳过和每日去重。
- 视频使用真实 FFmpeg 抽帧，B 站短链与公开元数据解析已验证。
- 配置与使用说明见 `docs/SCHEDULER_MEDIA.md`，本地 `scheduler.json` 被 Git 忽略。
