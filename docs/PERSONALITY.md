# 人格与群友长期记忆

ds_qq 的人格由本地文本定义，长期记忆由 SQLite 保存。两者在每次聊天时组合成 system prompt，原始消息仍按原有上下文窗口发送。

## 1. 启用人格文件

```bash
cp persona.example.txt persona.txt
```

编辑 `persona.txt` 后重启 `dsqq-bot`。该文件被 Git 忽略，可以放入自己的角色设定，但不要写入 API Key、密码或真实隐私。

默认模板是一只叫“大肥鱼”的小鲸鱼：热心、聪明、松弛、有一点憨憨的幽默，但在技术问题和朋友难过时保持严谨与分寸。你可以调整：

- 名字、口癖和常用语气；
- 默认回复长度与幽默程度；
- 与五位群友相处的边界；
- 什么情况下应该认真、简短或主动追问。

建议写具体行为，而不是只写“有趣”“像真人”。例如“默认 1～4 句，不每次都用问题结尾”比“说话自然”更稳定。

未创建 `persona.txt` 时，继续使用 `.env` 中的 `BOT_SYSTEM_PROMPT`。

## 2. 机器人如何学习

- 白名单群中的用户消息会持续保存，并更新每位成员的互动次数与昵称。
- 默认积累 **12 条用户消息**后，在下一次 @机器人时额外调用一次 DeepSeek 整理长期记忆。
- 单批最多整理 **60 条**，提炼群共同经历、相处备注和成员明确表达的稳定事实。
- 整理结果存入 `group_memory` 和 `member_memory`，后续聊天按需注入人格 prompt。
- 整理失败不会阻断正常聊天，也不会推进整理位置；下一次聊天会重试。
- `/new` 只清空短期会话上下文，**不会删除长期相处记忆**。

这是一种有成本的批量整理机制，不是每条消息都调用模型。看板“最近 API 调用”的“用途”会区分“群聊”和“记忆整理”。

## 3. 群命令

| 命令 | 作用 |
| --- | --- |
| `/memory` | 查看本群摘要、当前用户自己的事实与相处备注，不展示其他成员资料 |
| `/forget` | 群主或管理员清除本群长期记忆，并把整理位置移到最新消息 |
| `/new` | 开启短期会话，保留长期相处记忆 |
| `/stats` | 查看原始消息和短期会话数量 |
| `/help` | 查看命令帮助 |

`/forget` 不会删除原始聊天数据库；它会防止机器人立即从全部旧消息重新学习。后续新消息仍会重新开始积累记忆。

## 4. 可选配置

在 `.env` 中调整：

```dotenv
BOT_PERSONA_FILE=persona.txt
BOT_MEMORY_INTERVAL_MESSAGES=12
BOT_MEMORY_BATCH_SIZE=60
BOT_MEMORY_MAX_FACTS=8
```

五人小群如果希望更快看到学习效果，可以临时把 `BOT_MEMORY_INTERVAL_MESSAGES` 调为 `6`。调小会增加 API 调用次数。

## 5. 记忆与隐私边界

- 只应提炼明确表达的偏好、共同事件和相处方式，不推断人格、情绪或关系亲疏。
- 不保存密码、密钥、Token、手机号、精确住址、财务信息或敏感推断。
- 模型返回的用户 ID 必须属于本批消息参与者，事实数量与文本长度均有限制。
- 长期记忆可能不准确。可以用 `/memory` 检查，并由管理员用 `/forget` 清除。
- 群消息与整理内容会发送到 DeepSeek，请确保群成员知情。
- 当前仅支持白名单群聊，私聊不会触发回复或长期记忆整理。
